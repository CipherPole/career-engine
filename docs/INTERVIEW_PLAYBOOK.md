## Common Technical Screening Questions (Quick Answers)

| Question | One-Line Answer |
|----------|-----------------|
| What's the difference between Terraform `plan` and `apply`? | `plan` shows what will change without executing; `apply` executes the changes. |
| How do you handle Terraform state in a team? | Remote state backend (S3 + DynamoDB lock table) with state locking to prevent concurrent modifications. |
| What is a Kubernetes Deployment vs. StatefulSet? | Deployment for stateless apps (pods are interchangeable); StatefulSet for stateful apps (stable network identity, persistent storage). |
| Explain Jenkins Pipeline vs. Declarative Pipeline | Scripted Pipeline is Groovy-based and flexible; Declarative is structured, readable, and enforces best practices — we used both at BofA. |
| How do you implement least-privilege in AWS IAM? | Use IAM roles with scoped policies attached to resources, avoid IAM users for programmatic access, use condition keys to restrict by source IP/time. |
| What is GitOps? | The practice of using Git as the single source of truth for declarative infrastructure and application configuration, with automated reconciliation (e.g., ArgoCD). |
