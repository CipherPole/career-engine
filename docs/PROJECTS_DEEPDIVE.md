**Entity:** CipherPole (Personal)
**Stage:** Active — Ongoing R&D
**Type:** R&D / Open Source (future)

### What It Is
A personal engineering lab combining Raspberry Pi microcomputers, Arduino microcontrollers, ROS (Robot Operating System), OpenCV computer vision, and MQTT-based home automation. The lab explores modular, AI-driven autonomous systems for home and hobby robotics applications.

### Tech Stack
- **Hardware:** Raspberry Pi 4/5, Arduino Uno/Mega, ESP32
- **Robotics OS:** ROS 2 (Robot Operating System)
- **Computer Vision:** OpenCV, Python, YOLO (object detection)
- **Protocols:** MQTT, I2C, SPI, GPIO
- **Home Automation:** Home Assistant integration, custom scripts
- **Languages:** Python, C++ (Arduino), Bash

### Why This Matters for Your Career
This differentiates you from purely enterprise DevOps candidates. Showing you build physical hardware systems that require the same IaC/automation thinking as cloud infrastructure signals:
- Hands-on systems thinking that goes all the way down to the hardware layer
- Python fluency beyond scripting — computer vision, sensor integration
- Entrepreneurial curiosity and self-directed learning

### Recruiter Story
> "I run a personal robotics and IoT lab using Raspberry Pi, Arduino, ROS, and computer vision. It keeps my systems thinking sharp at the lowest abstraction levels — if I can automate hardware, I can automate anything. It's also where I prototype AI-assisted automation ideas before evaluating them for enterprise application."

## Portfolio Strategy

### Recommended GitHub Repos to Make Public First
1. **Terraform module** (e.g., reusable EKS cluster Terraform module) — directly showcases your #1 enterprise skill
2. **Playwright test framework** — demonstrates QA automation at scale
3. **Arduino/Raspberry Pi automation script** — unique differentiator vs. pure software engineers
4. **Docker Compose demo stack** — accessible, widely understood, shows container fluency

### How to Write a Good GitHub README for Portfolio Repos
Each repo should have:
```markdown
# [Project Name]

## What This Does
[1–2 sentences. Business problem it solves.]

## Why I Built It
[1–2 sentences. Ties to your professional experience.]

## Tech Stack
[Badges: AWS, K8s, Terraform, etc.]

## Architecture
[Simple diagram or bullet points]

## How to Run It
[3–5 step guide. Even if it's just for demo purposes.]
```
